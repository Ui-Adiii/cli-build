GET STARTED

Set up in a few commands.

Clone the repository, install dependencies, link the CLI, and add your NVIDIA API key.

01 — INSTALL

Install from source

Bun

Run these commands in your terminal. This uses the repository's current Bun-based setup.

Terminal
git clone https://github.com/ui-Adiii/cli-build.git
cd cli-build
bun install
bun link

i Run bun link from inside the cloned project directory.

02CONFIGURE

Add your API key

Configure the NVIDIA API key used by CLI Build.

Terminal
cli-build config set nvidia-api-key "your_key"
03LAUNCH

Start CLI Build

Launch the interactive command-line assistant.

Terminal
cli-build wakeup

REFERENCE

Configuration

Optional environment variables for connecting integrations and customizing model behavior.

VariableDescription
NVIDIA_DEFAULT_MODELDefault model for Ask and Agent modes.
FIRECRAWL_API_KEYEnables optional web search.
TELEGRAM_BOT_TOKENEnables Telegram integration.
TELEGRAM_OWNER_IDRestricts Telegram access to the configured owner ID.
SAFE BY DESIGN

Stay in control.

A few important practices when configuring and using your CLI.

01

Keep secrets private

Never commit .env or ~/.cli-build/config.json to version control.

02

Limit Telegram access

Configure the owner ID so Telegram access is restricted to the intended user.

03

Review file operations

Inspect staged changes and approve operations before they are applied to disk.
